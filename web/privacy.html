隱私權政策與個人資料保護規範

生效日期：2026 年 09 月 01 日 • 最新修訂：2026 年 09 月 05 日 • 適用規範：歐盟 GDPR / 台灣個人資料保護法
🛡️ 我們的核心隱私承諾

貓貓機器人 (CatBot 2.0) 團隊高度重視您的個人隱私與資料安全。我們遵循「最小化資料蒐集原則」，僅儲存維持服務運作所需的最少資料。所有資料均保存在安全隔離的伺服器本地 SQLite WAL 資料庫中，絕不轉售、分享、出租或用於任何廣告追蹤與商業側寫。

一、資料蒐集範圍與保存項目 (公開透明清單)

依據本機器人之系統原始碼 (src/utils/db.js)，當您使用機器人時，系統僅在必要範圍內記錄以下項目：

資料庫資料表 儲存內容與欄位 保存目的與生命週期
ai_memory Discord User ID、角色 (User/Bot)、對話內容、時間戳記 提供連續自然的多輪 AI 對話上下文。系統僅保留最近 50 則對話，逾時或手動清除後自動修剪抹除。
user_longterm_memories Discord User ID、使用者主動記錄之偏好內容、時間戳記 儲存您透過 /記憶系統 指令主動請 AI 記住的個人喜好（例如稱呼、寫作風格等）。
user_custom_personas Discord User ID、槽位編號 (1~3)、人設名稱、自訂 Prompt 儲存您透過 /製作人設 建立的客製化 AI 提示詞，最多 3 組。
ai_user_persona
ai_user_model		 Discord User ID、當前選擇之人設鍵值與偏好模型鍵值 記錄您個人當前偏好的對話風格與模型路由偏好。
ai_user_quota
ai_guild_quota		 User ID / Guild ID、日期字串 (YYYY-MM-DD)、當日累計調用次數 落實公平使用防護（個人 80 句/日、伺服器 500 句/日）。每日 00:00 自動歸零重計。
warnings Guild ID、受處分成員 ID、處分原因、執行管理員 ID 與 Tag、時間戳記 提供個別 Discord 伺服器管理員查詢與維護社群違規紀錄，僅於該伺服器內調用。
tickets Guild ID、頻道 ID、開單成員 ID、問題分類、標題、狀態、關閉者 客服單工單流轉管理，關閉時可由工作人員匯出 HTML Transcript 結案存檔。
guild_settings
banned_words		 Guild ID、歡迎頻道 ID、自訂歡迎詞與背景圖、伺服器違禁詞清單 個別伺服器管理員自訂之自動化設定，供歡迎模組與防護系統比對使用。

二、我們絕對不會蒐集的資料 (What We Never Collect)

為消弭使用者對機器人隱私之疑慮，本團隊鄭重聲明：

  • 絕不常規竊聽私訊 (DMs)：機器人絕不會監聽或記錄使用者的私人訊息，除非您在私訊中主動向機器人發起對話或下達指令。
  • 絕不儲存密碼生成結果：透過 /休閒娛樂 密碼生成 所產生的隨機安全密碼，純粹於伺服器記憶體中透過密碼學安全函式即時運算，並以「僅您可見 (Ephemeral)」訊息回傳，不寫入任何日誌或資料庫。
  • 絕不蒐集真實姓名與實體身分：我們不索取亦不擁有您的真實身分證字號、護照、實體地址、銀行帳號或信用卡資料。
  • 絕不販售資料給第三方：我們絕不會將您的對話內容或 Discord ID 提供予廣告商、數據仲介商進行商業變現。

三、第三方服務串接與資料傳輸說明

本機器人為實現進階 AI 推理、即時氣象與大眾交通時刻查詢，會透過端到端加密連線 (HTTPS/TLS) 與以下第三方合作夥伴進行最小化資料傳輸：

  • OpenRouter / OpenAI / Google Gemini：當您與 AI 進行對話或生成圖片時，您當前的訊息及最近上下文會以加密格式傳輸至模型推論伺服器。依據官方 API 服務條款，這些 API 調用資料預設不會被用於公開大模型之二次訓練。
  • 中華民國交通部中央氣象署 (CWA) / Open-Meteo：在您查詢天氣或地震速報時，僅會傳遞欲查詢之縣市名稱或地理座標，絕不包含任何使用者個人資訊。
  • 台灣高鐵 (THSR) / 台灣鐵路 (TRA) 查詢服務：僅傳送起訖車站代碼或車次編號進行時刻與票價檢索。
  • Cloudflare Turnstile (人機驗證)：在少數防範惡意自動化機器人濫用之情境下，僅驗證瀏覽器人機 Token，用於確認為真實人類使用者。

四、歐盟 GDPR「被遺忘權」與一鍵抹除機制 (Right to be Forgotten)

貓貓機器人全面落實歐盟《一般資料保護規範》(GDPR) 第 17 條賦予之「被遺忘權（刪除權）」。您隨時擁有對自身個人資料的最高掌控權，無需填寫冗長表單或寄信申請：

🗑️ 如何一鍵徹底清除屬於您的所有資料？
  1. 在任何有貓貓機器人的 Discord 頻道中輸入斜線指令：/使用條款
  2. 機器人將回傳一個僅您自己看得到的個人隱私面版，即時統計您目前在系統中的資料筆數（短期對話數、長期記憶數、自訂人設槽位數）。
  3. 點擊面板下方的紅色按鈕：「🗑️ 永久清除並抹除我的所有個人資料」。
  4. 系統將立即啟動 SQLite ACID 資料庫事務鎖，原子化、永久且無可挽回地徹底刪除您在 ai_memory、user_longterm_memories、user_custom_personas、ai_user_persona 與 ai_user_model 中的所有紀錄！

五、技術安全防護措施 (Security Measures)

為防止未經授權之存取、外洩、竄改或破壞，本機器人實施下列多層架構防護：

  • SQLite 3 WAL 引擎事務隔離：所有資料存取皆透過參數化查詢 (Prepared Statements) 與 transaction() 交易鎖封裝，徹底杜絕 SQL 注入攻擊。
  • SSRF (伺服器端請求偽造) 內網防禦：在執行網頁抓取或 Agent 瀏覽時，自動攔截並阻斷對 127.0.0.1、10.0.0.0/8、192.168.0.0/16 等內網私有 IP 之連線請求。
  • Zip Bomb 炸彈解壓縮防護：嚴格限制上傳檔案之解壓展開比例與單檔上限，防止記憶體耗盡型攻擊。
  • Docker 安全沙箱環境：使用者執行程式碼測試時，均於資源受限（限制 CPU、記憶體與網路連線）之獨立容器內運作，並於 1 分鐘後自動強制銷毀。

六、政策修訂與隱私諮詢管道

本隱私權政策可能隨技術升級、法規要求或新功能上線而進行滾動式修訂。重大實質變更將在官方社群伺服器進行公告。

  • 官方 Discord 支援伺服器：點此進入隱私反饋頻道
