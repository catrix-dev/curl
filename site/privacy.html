隱私權政策

最後更新日期：2026 年 9 月 6 日

歡迎使用 curl（以下簡稱「本機器人」）。我們高度重視用戶的個人資料隱私與社群安全。本隱私權政策旨在透明揭露本機器人在 Discord 伺服器中收集、處理、儲存及保護您資料的方式。

1. 我們收集的資料項目

本機器人僅收集維持機器人功能正常運作所必需的最低限度資料：

  • 基礎識別資料：用戶 ID（User ID）與伺服器 ID（Guild ID）、頻道 ID、角色 ID，用於區分各伺服器獨立資料庫與用戶識別。
  • 等級與經驗值：發言活躍度統計、等級與累積 EXP。
  • 簽到與成就記錄：每日簽到時間戳、已解鎖成就及遊戲統計。
  • 管理與安全記錄：警告紀錄（原因、時間戳、執行管理員 ID）、違規處罰日誌。
  • 生日資訊：僅在用戶主動使用 /生日 設定 時記錄月份與日期（不包含出生年份）。
  • 客服工單對話：用戶主動建立工單時產生的對話記錄，關閉後生成 HTML 歸檔供管理員備查。

我們絕不收集：真實姓名、信用卡或付款資訊、實體地址、電話號碼或私人密碼。

2. 資料的使用目的

  • 執行伺服器管理與安全過濾（防刷屏、釣魚連結攔截、警告處罰）。
  • 提供互動功能（等級排行榜、成就解鎖、簽到獎勵、生日提醒）。
  • 網頁控制台（Web Dashboard）供伺服器管理員配置模組功能。
  • 技術除錯與服務穩定性維護。

3. 資料儲存與保護機制

  • 儲存位置：所有資料均保存在安全的伺服器本機 JSON 資料庫中，未經授權無法從外部直接存取。
  • 傳輸加密：所有與 Discord API 及 Web 後台的通訊均強制使用 HTTPS / WSS 加密傳輸。
  • 訪問控制：除伺服器管理員能查看該伺服器專屬設定外，第三方無法跨服查看其他伺服器資料。

4. 資料分享與第三方揭露

我們承諾：

  • 不會將您的資料出售、出租或以商業目的提供給第三方。
  • 不會將資料用於廣告投放、用戶畫像或任何形式的商業分析。
  • 僅在法律強制要求或保護用戶安全的必要情況下，才可能向相關主管機關揭露必要資訊。

5. 資料保留期限

  • 伺服器資料在機器人離開該伺服器後，管理員可要求立即刪除；否則將於 180 天後自動清除。
  • 用戶可透過管理員使用重置指令，清除個人等級、簽到、生日等資料。
  • 工單歸檔文件依伺服器管理員政策保留，可由管理員自行刪除。

6. 用戶權利

您有權：

  • 請求查看本機器人儲存的您的個人資料。
  • 請求刪除您的個人資料（部分資料需透過伺服器管理員操作）。
  • 選擇不使用特定功能（如不設定生日、不參與遊戲等）。

7. 政策變更

本隱私政策可能因功能更新或法規要求而修訂。重大變更將在 Discord 公告頻道提前通知。繼續使用本機器人即視為接受最新版本政策。
